# Reference papers

The PDFs are **not stored in this repository**. They are attached to a GitHub
Release instead, so the repository stays small and clones stay fast.

**Download them here:**
<https://github.com/Preygle/satellite-ecomony-predection/releases/tag/papers-v1>

Or fetch all 20 at once with the GitHub command line tool:

```bash
gh release download papers-v1 --dir papers
```

## What is in the set

**20 papers, 19 published in 2020 or later**, grouped by theme:

| Theme | Papers |
|---|---|
| A — Nighttime light as an activity proxy | 6 |
| B — Measuring built-up extent | 5 |
| C — Inferring activity and vacancy | 3 |
| D — Predicting future urban expansion | 4 |
| E — Environmental consequences | 2 |

## Licences

Every paper is open access. Files are redistributed unmodified, for
non-commercial academic use, with attribution. The licence for each one is
listed in the release notes. Seventeen are Creative Commons; three are author
preprints on arXiv under arXiv's default distribution licence.
